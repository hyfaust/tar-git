# tgit - Structured Document Version Manager

[English](./README.md) | [中文](./README.zh.md)

[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)

A lightweight command-line tool for version management of structured documents (`.docx`, `.xlsx`, `.pptx`) and archives (`.tar`, `.tar.gz`, `.zip`). Built on Git as the storage engine, it provides a simplified interface so non-technical users can easily track document change history.

## 📦 Installation

```bash
# Clone the project and run from the directory
python -m tgit --help

# Or use the convenience scripts (Windows / Linux)
tgit.bat --help
tgit.sh --help
```

## 🚀 Quick Start

### 1. Initialize a repository

Navigate to a directory containing documents and run:

```bash
tgit init
```

This automatically:
- Creates a Git repository (`.git/`) directly in the working directory
- Generates `.gitignore` from `tgit.toml` to exclude archive originals
- Extracts archives in-place (e.g., `report.docx` → `report_docx/`)
- Creates the initial commit and version tag `v1.00`

### 2. Commit changes

After modifying documents, run:

```bash
tgit commit -m "Updated chapter 3 of the report"
```

### 3. View history and status

```bash
tgit log
tgit status
```

### 4. Restore an older version

```bash
tgit restore --at v1.02
tgit restore --at v1.02 -y   # Skip confirmation
```

### 5. View differences

```bash
tgit diff                        # Compare with the previous version
tgit diff --at v1.01             # Compare with a specific version
tgit diff --docx report.docx     # Use a custom diff tool
```

## 📖 Command Reference

| Command | Description |
|---------|-------------|
| `tgit init` | Initialize repository, generate `.gitignore` from config |
| `tgit commit [-m MSG]` | Commit changes, auto-detect and tag |
| `tgit version N` | Create major version tag `vN.00` |
| `tgit restore --at VER [-y]` | Restore to a specific version |
| `tgit diff [--at VER] [--docx]` | View differences |
| `tgit rebuild` | Rebuild missing archives from git |
| `tgit autosave [FILE]` | Auto-detect changes and commit |
| `tgit daemon [--interval N]` | Timed auto-save daemon |
| `tgit log [-n N] [--graph]` | View version history |
| `tgit tag` | List tags (proxies git tag) |
| `tgit status` | View repository status |

**Common flags:**
- `-y, --yes` — Skip interactive confirmation (for `restore`)

## ⚙️ Configuration

### `tgit.toml`

Configure archive formats, custom diff tools, and general settings:

```toml
# .docx extract/pack (built-in, no external tools)
[compression.docx]
extract_cmd = ["python", "-c", "import zipfile,sys,os; ...", "{src}", "{dst}"]
pack_cmd    = ["python", "-c", "import zipfile,sys,os; ...", "{src}", "{dst}"]
extract_to  = "{name}_{suffix}"   # test.docx → test_docx/

# .docx custom diff
[diff.docx]
script = "word_diff.py"

# General settings
[tgit]
autosave_interval = 300
gitignore_ignore = ["*.bak", "*.tmp", "~$*"]
```

**Extract directory naming (`extract_to`):**

| Template | Example | Notes |
|----------|---------|-------|
| `{name}_{suffix}` (default) | `test.docx` → `test_docx/` | Safe on all platforms |
| `{src_name}` | `test.docx` → `test.docx/` | ⚠️ Windows: conflicts with archive file |

**Placeholders:**
- `{src}` — Source file path (archive for extract, dir for pack)
- `{dst}` — Destination path (dir for extract, archive for pack)
- `{name}` — Filename stem (e.g., `test` from `test.docx`)
- `{suffix}` — Extension (e.g., `docx`)
- `{src_name}` — Full source filename (e.g., `test.docx`)

### `.gitignore`

Auto-generated by `tgit init` from `tgit.toml`. Excludes archive originals so only extracted directories are tracked. Re-run `tgit init` to regenerate.

## 🗂️ Directory Structure

```
working-directory/
├── .git/                  # Git repository (directly in working dir)
├── .gitignore             # Auto-generated, excludes archive originals
├── hashes.json            # File hash records for change detection
├── tgit.toml              # tgit configuration
├── report.docx            # Original archive (gitignored)
├── report_docx/           # Extracted contents (tracked by git)
│   ├── word/
│   └── [Content_Types].xml
├── data.xlsx              # Original archive (gitignored)
├── data_xlsx/             # Extracted contents (tracked by git)
└── notes.txt              # Plain file (tracked directly by git)
```

**Key design principles:**
- `.git/` lives directly in the working directory — no intermediate staging
- Archives are extracted in-place alongside originals
- Archive originals are gitignored; extracted directories are tracked
- Plain files are tracked directly by Git, no copying needed
- `hashes.json` enables efficient change detection

## ⚙️ Technical Details

- **Change detection**: SHA-256 hash comparison; only changed files are processed
- **Version tags**: Git annotated tags, format `v{major}.{minor:02d}`
- **Extraction**: `.docx`/`.xlsx`/`.pptx` use Python `zipfile`; `.tar`/`.tar.gz` use system `tar`
- **Custom diff**: Configure per-format diff tools via `tgit.toml`
- **Rebuild**: Restores plain files via `git show`, archives via `git ls-tree` + pack commands

## 🔧 Advanced Usage

### Use Git directly

tgit does not prevent direct Git usage:

```bash
tgit log --oneline
tgit git branch feature-xxx
tgit git checkout feature-xxx
```

### Recover deleted files

```bash
tgit log                    # View history
tgit restore --at v1.02     # Restore to before deletion
```

### Rebuild missing archives

If an archive file is deleted but its extracted directory exists in git:

```bash
tgit rebuild    # Restores missing files from git history
```

### Auto-save

```bash
# Auto-commit after editing
tgit autosave report.docx

# Background timed save (every 10 minutes)
tgit daemon --interval 600
```
