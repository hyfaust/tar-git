## Problem
You need to configure `tgit.toml` to manage different archive formats with their appropriate extract/pack commands, optionally attach custom diff tools, and control `.gitignore` generation.

## Config structure

`tgit.toml` has three sections:

```toml
[compression.<suffix>]   # Archive format definitions
[diff.<suffix>]          # Custom diff tools
[tgit]                   # General settings (including gitignore_ignore)
```

## Pattern 1: ZIP-based formats (xlsx, pptx, docx)

Office XML formats (.docx, .xlsx, .pptx) are ZIP archives internally. Use Python's `zipfile` module — no external tools needed.

```toml
[compression.xlsx]
extract_cmd = ["python", "-c",
    "import zipfile,sys,os; s,d=sys.argv[1],sys.argv[2]; os.makedirs(d,exist_ok=True); zipfile.ZipFile(s).extractall(d)",
    "{src}", "{dst}"]
pack_cmd    = ["python", "-c",
    "import zipfile,sys,os; s,d=sys.argv[1],sys.argv[2]; z=zipfile.ZipFile(d,'w',zipfile.ZIP_DEFLATED); "
    "[z.write(os.path.join(r,f),os.path.relpath(os.path.join(r,f),s)) for r,_,fs in os.walk(s) for f in fs]; z.close()",
    "{src}", "{dst}"]
extract_to  = "{name}_{suffix}"
```

**Key points:**
- `extract_cmd`: `ZipFile(src).extractall(dst)` — simple and preserves structure
- `pack_cmd`: Walk `src` dir, write each file into a new zip at `dst`
- `ZIP_DEFLATED` for compression; use `ZIP_STORED` if you want no compression
- Same pattern works for `.pptx` and `.docx` — just copy and change the section name

### Built-in defaults
tgit has built-in defaults for `docx`, so you only need to declare it in tgit.toml to **override**. For `xlsx` and `pptx`, you **must** declare them explicitly since they have no built-in.

## Pattern 2: Tar-based formats (tar.gz, tar.bz2, tar)

Use the system `tar` command directly:

```toml
[compression.tar.gz]
extract_cmd = ["tar", "xzf", "{src}", "-C", "{dst}"]
pack_cmd    = ["tar", "czf", "{dst}", "-C", "{src}", "."]
extract_to  = "{name}_{suffix}"

[compression.tar.bz2]
extract_cmd = ["tar", "xjf", "{src}", "-C", "{dst}"]
pack_cmd    = ["tar", "cjf", "{dst}", "-C", "{src}", "."]
extract_to  = "{name}_{suffix}"

[compression.tar]
extract_cmd = ["tar", "xf", "{src}", "-C", "{dst}"]
pack_cmd    = ["tar", "cf", "{dst}", "-C", "{src}", "."]
extract_to  = "{name}_{suffix}"
```

**Flags:**
- `xzf` = extract + gzip, `czf` = create + gzip
- `xjf` = extract + bzip2, `cjf` = create + bzip2
- `xf`/`cf` = uncompressed tar

## Pattern 3: Custom diff tool via script

Attach a Python script to a file suffix for specialized diffing:

```toml
[diff.docx]
script = "word_diff.py"
```

**Requirements for the script:**
- Must accept two positional args: `file1 file2` (old and new versions)
- Must print diff output to stdout
- Exit code 0 = no difference, 1 = difference found, 2 = error
- Path is relative to the project root (where tgit.toml lives)

**Alternative: inline command** (no script file needed):

```toml
[diff.csv]
cmd = ["diff", "--color=auto"]
```

## Placeholder reference

| Placeholder | Meaning | Example |
|---|---|---|
| `{src}` | Source file/directory | Working-dir file for extract, staging-dir for pack |
| `{dst}` | Destination file/directory | Staging-dir for extract, working-dir for pack |
| `{name}` | File stem (no suffix) | `report` from `report.docx` |
| `{suffix}` | File extension | `docx` from `report.docx` |

**Important:** `src` and `dst` are automatically swapped by `_expand()` based on the `is_pack` flag. You write the template once and it works for both directions.

## `.gitignore` generation

`.gitignore` is auto-generated by `tgit init` from `tgit.toml`. It excludes archive originals so only extracted directories are tracked. Re-run `tgit init` to regenerate.

Add extra patterns via `gitignore_ignore`:

```toml
[tgit]
gitignore_ignore = ["*.bak", "*.tmp", "~$*", "*.part"]
```

Generated `.gitignore` example:
```gitignore
# Auto-generated by tgit
*.docx
*.tar
*.tar.gz
*.zip

# User-defined ignores
*.bak
*.tmp
~$*
```

## General settings

```toml
[tgit]
autosave_interval = 300   # seconds; 0 = disabled
gitignore_ignore = ["*.bak", "*.tmp", "~$*"]  # extra patterns for .gitignore
```

## Gotchas

- **Config merges with defaults** — tgit.toml entries override built-in defaults, not replace them. A `[compression.docx]` section only overrides what you specify.
- **`extract_to` determines extracted directory name** — default is `{name}_{suffix}` (e.g., `test.docx` → `test_docx/`). Required on Windows to avoid file/dir name collision.
- **Script paths are relative to project root** — not to `.git/` or the tgit package.
- **tar requires `.` at end of pack_cmd** — `tar czf dst -C src .` (note the dot). Without it, tar may produce unexpected directory structure.
